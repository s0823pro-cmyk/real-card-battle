JOBLESS / プライバシーポリシー

最終改定日：2026年9月2日

アプリ「JOBLESS」（以下「本アプリ」）における、利用者情報の取り扱いについて定めます。

1. 取得する情報

本アプリは、次の情報を取得・保存または処理します。

  • 端末内のゲーム進行：ゲーム進行状況、実績、図鑑、チュートリアルの確認状況等（端末のローカルストレージに保存）
  • 端末内の設定：言語、音量、画像の事前読み込み設定、購入済み機能の有効状態等（端末のローカルストレージに保存）
  • 本アプリが生成する端末 UUID：ランキングおよび利用統計を同じ利用者の記録として関連付けるため、本アプリがランダムに生成する識別子。端末の製造番号ではなく、氏名やメールアドレスを直接含みません。起動時にサーバへ自動送信されます。
  • ランキング情報：利用者が入力するランキング名、職業別スコア、選択したバッジ、順位、優勝記録等。ランキング参加に同意した場合、ランキング名、スコア、順位、バッジ等が他の利用者に公開されます。
  • プレイ統計：職業、プレイ回数、勝敗、撃破数、獲得ゴールド、連勝数、プレイ時間、到達・クリアエリア、使用カード、撃破した敵、最終利用日時等。起動時およびバトル終了時にサーバへ自動送信されます。
  • 旧バージョンの Apple 連携識別子：バージョン 8.0 より前に利用者自身が Apple ID 連携を行った場合、Apple が本アプリ向けに発行した利用者識別子を、端末 UUID との連携情報として保存しています。本アプリはこの連携により氏名、メールアドレスまたはパスワードを取得していません。バージョン 8.0 では新しい Apple ID 連携を提供しません。
  • 広告関連情報：Google Mobile Ads（AdMob）による広告の配信・効果測定・不正防止のため、端末または広告の識別子、IP アドレス等から推定されるおおよその位置情報、広告データ、広告や本アプリの操作情報、クラッシュ・性能・その他の診断情報等が Google により処理されることがあります。端末識別子は、他社のアプリやウェブサイトをまたぐ広告配信・測定に使用される場合があります。
  • アプリ内課金情報：購入・復元のため、商品 ID、取引情報、購入状態等が Apple の App Store により処理されます。開発者はクレジットカード番号等の決済手段を取得・保存しません。
  • 通信情報：サーバへの接続に伴う IP アドレス、日時、HTTP ヘッダー、セキュリティ関連ログ等が、サーバ基盤を提供する Cloudflare により処理されることがあります。

2. 利用目的

  • ゲーム進行の保存、本アプリの提供・運営・サポート
  • ランキングの運営、スコア・順位・バッジ・優勝記録の管理と表示
  • 利用状況の集計、ゲームバランスの調整、不具合解析および品質向上
  • 不正なスコア送信、サービス妨害その他の不正利用の防止
  • 広告の配信、効果測定および不正防止
  • アプリ内課金の処理および購入済み機能の復元
  • 法令に基づく対応

3. 公開および外部サービスへの送信

開発者は利用者情報を販売しません。ランキング参加に同意した利用者のランキング名、スコア、順位、バッジ等は、ランキング機能上で一般公開されます。また、本アプリの提供に必要な範囲で、次の外部サービスへ情報が送信されます。

  • Cloudflare, Inc.：Cloudflare Workers および D1 を利用したランキング・統計データの処理と保存、通信の保護
  • Google LLC：Google Mobile Ads（AdMob）による広告配信、効果測定、不正防止。取り扱いは Google プライバシーポリシーをご確認ください。
  • Apple Inc.：App Store によるアプリ内課金の購入・復元および取引管理

このほか、法令に基づく場合、生命・身体・財産の保護に必要な場合、または事業承継に伴う場合を除き、利用者の同意なく個人データを第三者へ提供しません。

4. 保存場所および国外での処理

ランキング情報、端末 UUID、プレイ統計および旧 Apple 連携識別子は、Cloudflare Workers / D1 を利用するサーバに保存されます。Cloudflare、Google および Apple のサービスでは、日本国外を含む地域で情報が処理される場合があります。

5. 保管期間

端末内のゲーム進行は、利用者がアカウントとサーバデータを削除するか、データを初期化するか、本アプリを削除するまで保存されます。言語、音量等の設定は利用者が変更するか本アプリを削除するまで保存されます。購入済み機能の端末内の有効状態は本アプリの削除まで保存される場合がありますが、購入履歴そのものは Apple が管理し、本アプリの「購入の復元」から再確認できます。サーバ上のランキング・統計データは、利用者が削除操作を行うまで、またはサービス運営上必要な期間保存されます。削除後も、法令上保存が必要な情報、ならびに外部サービスが各社のポリシーに基づき保持する情報が一定期間残る場合があります。

6. アカウントおよびサーバデータの削除

本アプリは、端末 UUID を単位とするサーバ記録を自動的に作成します。利用者はアプリ内の「設定 → データ → アカウントとサーバーデータを削除」から、確認後ただちに次の情報を削除できます。

  • 端末 UUID および旧 Apple 連携識別子とのリンク
  • ランキング名、スコア、公開順位、バッジ等
  • 利用統計およびその他の端末 UUID に関連付けられたサーバデータ

確定済みの優勝履歴は大会結果の整合性を保つため、端末 UUID を本人と再関連付けできない記録用 ID に置き換え、ランキング名を「削除済みユーザー」に変更した匿名記録のみを保持します。この削除操作では、この端末のゲーム進行、図鑑、実績等もあわせて消去します。購入済み機能、言語、音量等の設定は保持されます。

アカウントとサーバデータの削除は、Apple が管理する購入履歴を削除せず、購入済み機能の返金を行うものではありません。

7. セキュリティ

開発者は、通信の暗号化、アクセス制限その他の合理的な安全管理措置により、取得した情報の漏えい、滅失、毀損および不正アクセスの防止に努めます。ただし、インターネット上の通信について完全な安全性を保証するものではありません。

8. お子様の利用

お子様が本アプリを利用する場合は、保護者の同意と監督のもとでご利用ください。必要に応じて各ストアおよび端末の保護者向け機能をご利用ください。

9. 開示・訂正等

法令に基づき、保有個人データの開示、訂正、利用停止等を求められる場合、本人確認のうえ合理的な範囲で対応します。

10. 本ポリシーの変更

開発者は、必要に応じて本ポリシーを変更できます。変更後の内容は本ページに掲載した時点で効力を生じます。

11. お問い合わせ

本ポリシーに関するお問い合わせは、アプリ配布ページに記載の開発者連絡先までご連絡ください。
