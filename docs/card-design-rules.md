# カード設計ルール

このドキュメントは、カード追加・調整時に守る共通仕様をまとめる。
実装時はここを基準に、表示崩れ・バランス崩壊・カード説明のズレを防ぐ。

## レアリティ枚数

全ジョブのカード枚数は以下に揃える。

```text
初期カード定義 5 / コモン 28 / アンコモン 23 / レア 12
合計 68
```

配達員の現在目標もこの枚数に合わせる。

## バッジ表示仕様

カードのバッジは、役割ごとに別枠で扱う。

### メインバッジ

カード種類を示す中央固定バッジ。

- アタック
- スキル
- パワー
- 装備

### 状態バッジ

カード名の左に最大2つまで表示する。
サブバッジ数には含めない。

- 消耗
- 消滅
- 自傷

自傷バッジを付ける基準:

- 確定で自分にHPダメージを受けるカードには付ける
- ランダム自傷でも、強いデメリットとして事前表示した方がよいカードには付ける
- 軽いランダム自傷まで全部に付けると表示がうるさくなるため、カードごとに判断する

表示優先度:

```text
消滅 > 消耗 > 自傷
```

2つ表示する場合は、1つのバッジ内で `/` 区切りにする。

```text
消耗/自傷
消滅/消耗
```

### サブバッジ

メインバッジの左右に表示する補助バッジ。
サブバッジは最大2個まで。

例:

```text
状態バッジ2個 + サブバッジ2個 = OK
消耗/自傷 + スタミナ + 不屈 = OK
```

```text
サブバッジ3個 = NG
スタミナ + 不屈 + 準備 = NG
```

サブバッジ対象:

- スタミナ
- 不屈
- 不動
- 準備
- 食材
- 調理
- 温存
- 追込

## 消耗・消滅

### 消耗

- 使用後、戦闘中の除外へ送る
- 戦闘終了後はデッキへ戻る
- 通常は1回使用で除外
- `battleUseLimit: 2` があるカードだけ、戦闘中2回使用後に除外

### 消滅

- 使用後、戦闘中の除外へ送る
- 戦闘終了後もデッキへ戻らない
- そのラン中のデッキから消える

## 配達員仕様

### スタミナ

- 最大10
- 自分のターン開始時に1減る
- スタミナが減るほどカードコストが+0.5秒
- スタミナ回復カードは1ターンに2枚まで

### 過労ダウン

- スタミナ0で発生
- 4ターン継続
- アタック・通常スキルは使用不可
- ブロックカード・不屈・不動カードは使用可能
- 過労中に使用可能なカードは固定3.5秒
- 復帰時はスタミナ6

### スタミナバッジを付ける条件

以下のいずれかに該当するカードに付ける。

- スタミナを回復する
- スタミナを消費する
- スタミナ量を参照して効果が変わる

以下には付けない。

- 単なるドロー
- 単なるコスト減
- 単なる連打
- 次ドロー確認

## 配達員カード調整方針

- 強いスタミナ回復は1回使用後除外
- 小さいスタミナ回復は2回使用後除外可
- 不動 + スタミナ + 消耗は、状態バッジ1個 + サブバッジ2個なので表示上はOK
- 消耗 + 自傷 + スタミナ + 不屈は、状態バッジ2個 + サブバッジ2個なので表示上はOK
- 状態バッジの消耗・消滅・自傷はサブバッジ数に含めない
- 状態バッジは最大2個。複数該当時は 消滅 > 消耗 > 自傷 の優先度で表示する
- スタミナ + 不屈 + 準備のようなサブバッジ3個構成は禁止
