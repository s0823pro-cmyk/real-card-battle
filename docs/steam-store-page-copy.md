# JOBLESS Steam Store Page Draft

## Short Description

無職から伝説へ。職業ごとにルールが変わるローグライクカードバトル。

## Short Description EN

Rise from joblessness to legend in a roguelike card battler where every job changes the rules.

## About This Game

JOBLESSは、カードを選び、時間を管理し、敵を倒しながら世界樹を目指すローグライクカードバトルです。

各ジョブには専用カード、専用ギミック、専用ストーリーがあります。大工は足場を組み、料理人は満腹度と料理ゲージを扱い、無職は逆境を力に変え、配達員はスピードと復帰力で戦います。

ランキングはスマホ版と共有されます。シーズンを制したプレイヤーの名前は、優勝者カードとしてゲーム内に残る可能性があります。

## About This Game EN

JOBLESS is a roguelike card battler where you choose cards, manage time, defeat enemies, and climb toward the World Tree.

Each job has its own cards, mechanics, and story. The Carpenter builds scaffolds, the Cook manages fullness and cooking gauges, the Unemployed turns adversity into strength, and the Courier fights with speed and recovery.

Rankings are shared with the mobile version. The name of a season champion may remain in the game as a winner card.

## Key Features

- 職業ごとに戦い方が変わるカードバトル

## Store Positioning

まずは「配信開始」よりも「近日登場」で公開し、ウィッシュリストを集める。Steam版の価値は、広告なし、買い切り、PCでじっくり遊べること、スマホ版とランキングを競えることに置く。

## Launch Notes

- 価格は買い切りを基本にする。
- 初回公開時点ではSteam実績やSteam Cloudは必須にしない。
- ストア公開後にPC操作感、画面比率、キーボード/マウス操作を優先して詰める。
- Steam固有の認証やSteam ID連携は、ランキング不正対策が必要になった段階で追加する。
