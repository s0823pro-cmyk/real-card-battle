# 警察官ジョブ案メモ

作成日: 2026-06-02

## 位置づけ

次バージョン以降の新ジョブ候補。

5.0は審査提出済みのため、審査中は実装しない。
実装する場合は別ブランチで進める。

## コンセプト

- ジョブ名: 警察官
- キャッチコピー: 守るために、踏み込む
- 方向性: 街の治安を守るファンタジー寄りの職業
- App Store審査向けに、現実の警察批判や過激な暴力表現には寄せない

## プレイ体験

防御しながら警戒を溜め、タイミングを見て制圧する。

既存職との差別化:

- 大工: 足場を積み上げて大ダメージ
- 料理人: 調理ゲージを爆発させる
- 無職: ピンチほど強くなる
- 配達員: 低コスト連打とスタミナ管理
- 警察官: 守りながら警戒を溜めて制圧する

## 固有メカニクス案

### MVP案: 警戒

- ブロック、防御系カード、巡回系カードで警戒を獲得
- 警戒を消費して攻撃、弱体、敵攻撃力ダウンを行う
- 防御寄りだが、溜めた後に大きく返せる

### 後回し候補: 証拠

- 特定カードで敵に証拠を付与
- 証拠がある敵に逮捕・制圧カードの追加効果
- MVPでは複雑化しやすいため初回実装では入れない

## 初期カード案

- 警棒打ち: 4ダメージ
- 防犯盾: 5ブロック
- 巡回: カード1枚ドロー、警戒+1
- 職務質問: 敵に弱体1、警戒+1
- 制圧: 警戒を全消費し、消費数x4ダメージ

## 追加カード案

- 一斉検挙: 全体ダメージ。警戒が高いほど強化
- 応援要請: カード2枚ドロー、次の攻撃を警戒分強化
- 現場封鎖: 大ブロック、敵に脆弱
- 取り調べ: 敵の攻撃力-3、警戒+2
- 逮捕状: 警戒5以上なら大ダメージと敵弱体
- パトロール強化: 毎ターン開始時に警戒+1
- 盾列展開: 次ターンまでブロックが残る

## 解放条件案

配達員でエリア1ボスを撃破すると解放。

既存の解放順:

大工 -> 料理人 -> 無職 -> 配達員 -> 警察官

## 実装方針メモ

- 最初は警戒ゲージのみでMVP実装する
- 証拠システムは後回し
- 既存の効果をなるべく流用する
  - draw
  - weak
  - vulnerable
  - debuff_enemy_atk
  - block_persist
- 新規メカニクスは最小限にする
- 新規アセットが必要なため、カード画像・ジョブシンボル・マップ背景は別作業に分ける

## 注意点

- 現実の警察不祥事、政治的主張、過度な暴力表現には寄せない
- 敵名やストーリーもファンタジー・治安維持・街のトラブル解決寄りにする
- 審査中の5.0には入れない
